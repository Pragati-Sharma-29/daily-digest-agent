## Agentic AI & Developer Tooling

### What happened
Agents are rapidly moving from experimental to production, and the infrastructure around them — version control, identity management, data semantics — is struggling to keep up. Today's key developments highlight both the promise and the gaps: Madrona flagged that coding agents have broken Git hosting, Google Cloud shipped agent security tooling, and a new wave of agent-native software platforms is emerging.

### Key stories
- **Agents broke Git hosting — Entire is what comes next** — Madrona published a sharp analysis arguing that coding agents, which operate at superhuman speed and scale, have fundamentally broken Git hosting systems designed for human-paced workflows, leading to a new generation of "agent-native" version control platforms like Entire. This is an underappreciated infrastructure inflection point that will matter enormously as agentic coding becomes standard practice. ([Madrona](https://www.madrona.com/agents-broke-git-hosting-entire-is-what-comes-next/))
- **Google Cloud launches IAM Helper Agent Skills and MCP Tools** — Google Cloud released new tooling to help developers secure agent identities at scale, including IAM Helper Agent Skills and Model Context Protocol (MCP) Tools for provisioning cloud resources and writing Terraform safely. As agents gain access to production infrastructure, identity and access management becomes a critical unsolved problem — this is Google's opening move in that space. ([GCP Blog](https://cloud.google.com/blog/products/identity-security/scale-agents-securely-with-iam-helper-agent-skills-and-mcp-tools/))
- **LookML in Google Knowledge Catalog is now GA** — Google Cloud announced general availability of LookML metadata indexing in Knowledge Catalog, enabling AI agents to not just access data but understand the business semantics and context behind it. This is a crucial distinction: production AI agents fail not because they lack data access, but because they lack data understanding. ([GCP Blog](https://cloud.google.com/blog/products/business-intelligence/lookml-metadata-indexing-in-knowledge-catalog-is-now-ga/))
- **The RealReal blocks AI agents from shopping its site** — Luxury resale platform The RealReal updated its bot defense systems to block AI agents from purchasing designer goods, following Meta Muse's agentic shopping launch. This is an early sign of the coming conflict between retailers and AI shopping agents, and raises real questions about how e-commerce will function when a significant share of "customers" are bots. ([The Verge](https://www.theverge.com/news/1018713/meta-muse-agentic-shopping-ai-the-realreal))

### What to watch
The agent-native infrastructure layer — version control, identity, data semantics — is where the next wave of developer tooling startups will emerge. Watch for more incumbents like GitHub and Jira to either adapt or face disruption from purpose-built agentic alternatives.

## Internet History & Platform Consolidation

### What happened
Two pieces today took a longer historical view of how we got to the current concentrated, platform-dominated internet. Ben Thompson argued the open internet is definitively over, while Asianometry published a deep-dive on how Linux and Windows dismantled UNIX's enterprise dominance in the 1990s — a cautionary parallel for anyone betting on incumbent platforms today.

### Key stories
- **Stratechery: The End of the Internet** — Ben Thompson published a landmark essay arguing that the era in which anyone could host a server on the open internet is definitively over — not just due to AI, but as the culmination of a decade-plus of consolidation into hyperscaler infrastructure. While the loss is real, Thompson argues the future holds different kinds of opportunity, though he doesn't shy away from the implications for open discourse and decentralized innovation. ([Stratechery](https://stratechery.com/2026/the-end-of-the-internet/))
- **Asianometry: How Linux and Windows ate UNIX** — Asianometry's video essay examines how the UNIX ecosystem — dominant on big-iron enterprise servers through the early 1990s — was completely dismantled by the combination of Intel's commodity silicon and the rise of Windows and Linux. It's a rich historical parallel for understanding how dominant platform ecosystems can be displaced by cheaper, more accessible alternatives. ([Asianometry](https://asianometry.passport.online/member/episode/how-linux-and-windows-ate-unix))

### What to watch
Thompson's "End of the Internet" thesis will generate significant debate. Watch for responses from decentralization advocates (Fediverse, Nostr, blockchain communities) and whether policymakers in the EU or elsewhere use the analysis to justify further antitrust action against hyperscalers.

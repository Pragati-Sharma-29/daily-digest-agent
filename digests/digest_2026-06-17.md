## AI Safety, Verification & Reliability

### What happened
Two significant developments addressed the reliability gap in AI systems today. OpenAI announced Deployment Simulation — a new methodology to predict how AI models will behave before they go live. Separately, Pramaana Labs raised a $27M seed round to build formal mathematical verification for AI outputs, specifically targeting high-stakes domains where errors carry serious consequences.

### Key stories
- **Predicting model behavior before release by simulating deployment** — OpenAI's Deployment Simulation uses real conversation data to model AI behavior at scale before a model ships, aiming to catch safety failures that internal testing misses. This is a meaningful step toward systematic pre-deployment evaluation, though the fundamental challenge of predicting emergent behavior in novel contexts remains unsolved. ([OpenAI](https://openai.com/index/deployment-simulation))
- **Pramaana Labs raises $27M seed round from Khosla Ventures to bring formal verification to AI** — Pramaana is building technology to make AI answers mathematically verifiable, targeting law, drug discovery, and tax preparation — sectors where a hallucinated answer can cause real harm. The $27M seed is an unusually large early-stage bet, signaling Khosla's conviction that verifiable AI is a foundational infrastructure problem, not a niche application. ([TechCrunch](https://techcrunch.com/2026/06/17/pramaana-labs-raises-27-million-seed-round-from-khosla-ventures-to-bring-formal-verification-to-ai/))

### What to watch
Formal verification for AI is technically ambitious — watch for Pramaana's first published results in their target verticals, and whether OpenAI's Deployment Simulation methodology becomes an industry standard or remains a proprietary internal tool.

## Cybersecurity & AI Vulnerabilities

### What happened
Two major security stories dominated today: a critical LLM-related vulnerability in Microsoft Copilot that allowed 2FA theft, and AMD's controversial removal of memory encryption from consumer CPUs. Separately, the cloud security startup Tamnoon received Insight Partners' attention for autonomous remediation of cloud misconfigurations, and Trustmi is tackling AI-powered payment fraud. The security posture of AI-integrated systems is deteriorating faster than defenses are being built.

### Key stories
- **Critical Copilot vulnerability allowed hackers to steal 2FA code from users** — The "SearchLeak" exploit in Microsoft Copilot represents a new class of LLM security failure: attackers could extract time-sensitive authentication codes by manipulating how the AI searched and processed user data. Ars Technica frames this as symptomatic of a broader, systemic failure in how the industry approaches LLM security. ([Ars Technica](https://arstechnica.com/security/2026/06/critical-copilot-vulnerability-allowed-hackers-to-seal-2fa-code-from-users/))
- **Users cry foul after AMD stripped memory crypto from its consumer CPUs** — AMD's removal of Transparent Secure Memory Encryption (TSME) from consumer processors appears to have been a deliberate, undisclosed decision — not a bug or oversight. This is particularly troubling because TSME protects against cold-boot attacks and physical memory access, and removing it without announcement erodes trust in the hardware security baseline. ([Ars Technica](https://arstechnica.com/security/2026/06/users-cry-foul-after-amd-stripped-memory-crypto-from-its-consumer-cpus/))
- **Windows and Linux users: The deadline to update Secure Boot keys is near** — An impending expiration of Secure Boot keys will affect both Windows and Linux systems, requiring users to act before their machine's boot security degrades. The intersection of this deadline with the AMD TSME removal creates a compounding hardware security concern for enterprise and consumer alike. ([Ars Technica](https://arstechnica.com/security/2026/06/windows-and-linux-users-the-deadline-to-update-secure-boot-keys-is-near/))
- **How Tamnoon is tackling the cloud security backlog with autonomous remediation** — Insight Partners' profile of Tamnoon highlights a core problem: organizations have visibility into cloud misconfigurations but lack the human bandwidth to fix them. Tamnoon's autonomous remediation approach directly addresses the "knowing but not fixing" gap that has made cloud misconfigurations the #1 enterprise attack vector. ([Insight Partners](https://www.insightpartners.com/ideas/tamnoon-leadership-story/))
- **How Trustmi uses AI to make sure every dollar goes where it should** — As ransomware has become harder to monetize, cybercriminals are pivoting to business payment fraud — intercepting wire transfers and redirecting funds. Trustmi applies AI to payment verification, catching fraudulent transfers before they execute. This is an emerging, high-value attack surface that most organizations are underprepared for. ([Insight Partners](https://www.insightpartners.com/ideas/trustmi-leadership-story/))

### What to watch
The SearchLeak Copilot vulnerability will likely trigger a broader review of LLM access to sensitive user data — watch for Microsoft's response and any industry-wide security framework updates. AMD's TSME removal demands a clear public explanation from the company.

## Security: PHP Armageddon & Certificate Crisis

### What happened
Two separate but simultaneous security crises shook the internet today. Critical vulnerabilities in PHP's core runtime were disclosed by Wiz Research and OpenAI's Patch the Planet initiative, with reports of active exploit code (PHP2Shell) enabling remote code execution on PHP sites. Simultaneously, eight compromised TLS intermediate certificates from Indian CA eMudhra were discovered, creating the potential for fraudulent SSL credentials for any server on the internet — a foundational trust crisis.

### Key stories
- **Critical PHP vulnerabilities CVE-2026-109618 and CVE-2026-109619** — Wiz Research, using AI-assisted techniques, discovered two critical flaws in PHP's core runtime: one enabling unauthenticated remote code execution and one enabling memory disclosure. PHP maintainers warned developers to prepare emergency patches, and EU cybersecurity officials told organizations that can't patch immediately to take affected servers offline. The dual nature of this story — AI both finding and potentially enabling exploitation of these bugs — is a preview of the double-edged sword AI represents for security. ([Ars Technica](https://arstechnica.com/security/2026/10/php-maintainers-tell-web-devs-to-prepare-themselves-for-critical-security-patches/)) / ([Google Cloud](https://cloud.google.com/blog/products/identity-security/responding-to-core-php-vulnerabilities-cve-2026-109618-cve-2026-109619/))

- **OpenAI's "Patch the Planet" initiative** — OpenAI launched a coordinated disclosure framework connecting security researchers, maintainers, and incident responders to address critical open source vulnerabilities at scale — and it was directly involved in uncovering the PHP flaws. This represents OpenAI moving into the security infrastructure space in a meaningful way, using agent-based research to find and responsibly disclose vulnerabilities that could affect billions of web users. ([OpenAI](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities))

- **eMudhra's CA keys cracked in milliseconds** — Eight intermediate TLS certificates issued by Indian certificate authority eMudhra were found to have critically weak 8-bit key material, crackable in milliseconds, allowing anyone to mint fraudulent web credentials for any internet server. The Indian government formed a special investigation team, and eMudhra's co-founder stated the vulnerable keys were created but never deployed commercially — though the discovery of compromised intermediate CAs is alarming regardless of deployment status. ([Ars Technica](https://arstechnica.com/security/2026/10/the-internet-goes-on-high-alert-after-discovery-of-8-compromised-tls-certs/)) / ([Economic Times](https://economictimes.indiatimes.com/tech/technology/vulnerable-keys-were-created-but-never-put-to-commercial-use-investigation-on-emudhra-cofounder/articleshow/135096778.cms))

- **LiteLLM PyPI package compromised with credential stealer and backdoor** — Version 1.107.0 of LiteLLM on PyPI was found to contain a credential stealer and backdoor, a supply chain attack targeting AI developers who rely on this popular LLM gateway library. Given LiteLLM's widespread use in enterprise AI stacks, the blast radius of this compromise could be significant — developers should audit their environments immediately. ([SafeDep](https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/))

- **Plex media server vulnerabilities under active exploitation** — A chain of four Plex vulnerabilities is being actively exploited to install malware on unpatched systems. This is a direct call to action for the large community of self-hosted Plex users: patch immediately or face compromise. ([Ars Technica](https://arstechnica.com/security/2026/10/recently-fixed-plex-media-vulnerabilities-are-being-exploited-to-install-malware/))

### What to watch
Monitor the PHP patch releases closely — PHP 8.2.35 is already out on GitHub, and additional emergency releases are expected. Track whether the PHP2Shell exploit code proliferates in the wild before organizations can patch. The eMudhra investigation may have broader implications for how CAs globally are audited for key quality.
